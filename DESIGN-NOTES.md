# САКП — редизайн по референсу Madani

Рабочие заметки проекта (дублируют локальную память Claude Code, чтобы контекст был доступен с любой машины).

## Файлы

- `sakp-all-screens-standalone.html` — **оригинал, не трогать**. Эталон для финального сравнения. 92 экрана САКП (Telegram Mini App для управления производством пластиковых изделий), дизайн-система «Промышленная точность».
- `sakp-all-screens-redesign.html` — **рабочая копия**, все правки дизайна делаются здесь.

## Устройство борда

- Figma-подобный дев-борд: 10 секций по ролям (вход, оператор, ОТК, склад продукции, склад сырья, менеджер, директор, аналитика, суперадмин, общие), каждый экран в рамке `.phone` шириной 320px.
- CSS: tokens.css → components.css (неймспейс `.v2`) → легаси styles.css → CSS обвязки борда. Вся разметка экранов — одна строка ~120 КБ. Скриптов нет, всё статично.
- Настоящие логи (`<pre>`) остаются моноширинными через дефолт браузера — переменная `--font-mono` переопределена на Inter (Madani без моно).

## Дизайн-система Madani (извлечена из Figma 2026-07-24)

### Цвета

| Токен | Значение | Использование |
|---|---|---|
| primary | `#9B2226` | бордовый: кнопки, футер, активные строки, бренд-панели |
| ink | `#1A2736` | основной текст (не чёрный) |
| text-secondary | `#8A8C8A` | вторичный текст |
| grey | `#ECECEC` | бордеры, secondary-кнопки |
| bg | `#FAFAFB` | фон страниц |
| card | `#FFF` 95% + background blur 30 | карточки |

### Типографика — Inter

- Display: Black 900, uppercase (52px на десктопе)
- Заголовки карточек: ExtraBold 800, 20px/130%
- Кнопки: SemiBold 600
- Body: Medium 500, 14px/140%, letter-spacing −1%

### Компоненты

- Кнопки: радиус 10px, паддинги 14–16 / 28–32; primary — заливка #9B2226 + белый текст; secondary — заливка #ECECEC + тёмный текст.
- Карточки: радиус 20px, бордер 1px #ECECEC, лёгкая тень.
- Бейджи: малый радиус (~7px), не «пилюли»; Sale — красный, New — тёмный #1A2736.
- Паттерны: активный пункт списка — бордовая заливка с белым текстом; секции-«ленты» сплошного бордового с белыми заголовками; формы на бордовой панели с белыми скруглёнными инпутами (лейблы белые, красная звёздочка); хлебные крошки; в заголовках часть фразы выделяется красным.

## Статус (2026-07-24)

Базовый рестайл применён к `sakp-all-screens-redesign.html`:

- токены (обе `:root`-секции, `.v2`, легаси-переменные) переведены на палитру Madani;
- кнопки `.mbtn`/`.gbtn`, чипы (радиус 7px), плитки, таббары;
- `.op-hero` — плоский бордовый; `.stat-hero` — плоские статусные заливки (без градиентов);
- `.badge-new`, `.badge-count`, `.dialog-msg` перекрашены, все синие/фиолетовые акценты убраны;
- подключён Inter (Google Fonts), заголовок борда переименован.

Проверено в браузере: mode, operator, director, otk, sa-logs — консистентно, рендерится 92/92.

### Известные артефакты (НЕ регрессии редизайна)

- ОТК-главная: цифры наезжают на длинные имена в строках отчётов — есть и в оригинале (горизонтальный скролл-контейнер мока).

### Возможные следующие шаги

- Углубление стиля: бордовые hero-«ленты» как у Madani, формы на бордовой подложке, активная строка списка с бордовой заливкой.
- `#2f6fb0` в разметке — это цвет красителя «Синий» (данные, не дизайн) — не перекрашивать.
