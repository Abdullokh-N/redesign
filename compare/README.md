# Сравнение «Было / Стало»

`Сравнение редизайна САКП.html` — все 92 экрана оригинала (`sakp-all-screens-standalone.html`) и редизайна (`sakp-all-screens-redesign.html`) рядом, с номерами. Различия обведены рамками, справа объяснение к каждой рамке, на первой странице сводка.

Открывается двойным щелчком, сервер не нужен. Интернет нужен только для шрифта Inter: без него замер обрезанных строк может немного разойтись, отчёт об этом предупредит.

## Пересборка

Отчёт — снимок: оба борда вшиты в него на момент сборки. После правок редизайна соберите заново (нужен Node.js), из корня репозитория:

```
node compare/build-compare.mjs compare/compare-template.html sakp-all-screens-standalone.html sakp-all-screens-redesign.html "compare/Сравнение редизайна САКП.html"
```

`compare-template.html` — сам отчёт без данных, `build-compare.mjs` вшивает в него оба борда. Сравнение считается в браузере при открытии, поэтому логику проверок правят в шаблоне.
